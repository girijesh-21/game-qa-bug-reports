# 🐞 Bug Report: Intermittent Frame Drops During Gameplay

## Bug ID
ER-PERF-011

## Title
Occasional frame drops and stuttering during gameplay on PC

## Game / Build
Elden Ring (PC) – Version 1.10

## Environment
- Platform: PC  
- GPU: NVIDIA GeForce RTX 3050 (Laptop)  
- CPU: Intel i5-11300H  
- RAM: 8/16 GB  
- OS: Windows 11 (Dual Boot with Linux)  

## Severity
Medium

## Priority
High

---

## Description
The game experiences intermittent frame drops and stuttering during gameplay, even when GPU and CPU usage remain within normal ranges. This issue started occurring after setting up a dual-boot system.

---

## Steps to Reproduce
1. Launch the game on Windows 11  
2. Load into any open-world area  
3. Move around or engage in combat  
4. Observe FPS and gameplay smoothness  

---

## Expected Result
Gameplay should remain smooth and stable with consistent frame rates.

---

## Actual Result
Sudden frame drops and stuttering occur intermittently, affecting gameplay experience.

---

## Frequency
Occurs frequently (every 5–10 minutes during gameplay)

---

## Additional Notes
- CPU usage observed around ~40–50% during gameplay  
- Issue was not present before enabling dual boot setup  
- Lowering graphics settings does not fully resolve the issue  
- More noticeable during combat and fast camera movement  

---

## Possible Causes (Hypothesis)
- Driver conflicts or improper GPU driver configuration after dual boot  
- Background processes affecting performance  
- Power management or thermal throttling issues
